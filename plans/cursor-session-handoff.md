# Старт новой сессии: Cursor → dsh-ide

**Состояние на 26.11.2026:** исследование сохранено. Пользователь хотел максимально широкий перечень возможностей Cursor, которых не хватает в `@local/dsh-ide`, а не только четыре идеи для ближайшего релиза. В рамках исследования менялись только документы; затем пункты №1–№5 реестра (regex и целое слово, Git diff в чат, ревью staged, черновик сообщения коммита, follow-up в Inline Edit) были реализованы в коде. Объект работы — основной плагин в корне репозитория, не вспомогательный редактор в `editor/`.

## Что читать

1. **Основной план — [реестр 68 возможностей](cursor-feature-gaps.md).** Номера стабильны для этой версии: 1–12 — ближайшие улучшения; 13–29 — редактор и контекст; 30–46 — браузер и работа с агентами; 47–68 — командные и внешние сервисы. Для конкретной задачи достаточно строки с её номером и раздела «Как превратить реестр в поставки».
2. **[Первоначальный план](cursor-docs-roadmap.md)** нужен только для подробной приёмки ревью, планов, правил и отладки. Четыре пункта в нём не заменяют реестр.
3. **[README → Управление](../README.md#управление)** и **[Ограничения](../README.md#ограничения)** — отправная точка для проверки текущей версии. В IDE уже есть поиск по содержимому с регулярными выражениями и целыми словами, ссылки на файл и строки в чате, Inline Edit с уточнением, Tab по слову, Git diff, патч в чат, ревью staged и черновик сообщения коммита, снимки хода. Нужен недостающий шаг, а не вторая реализация этих возможностей.

## Как продолжать

- Если попросили **оценить или дополнить** план: взять указанную строку, проверить ссылку Cursor и фактический сценарий в dsh-ide. `−` означает документированное ограничение, `Δ` — частичное покрытие, `?` — наличие ещё не проверено, `↔` — интеграцию с Harness или внешним сервисом. Отсутствие описания не доказывает отсутствие функции.
- Если попросили **реализовать**: взять один выбранный пункт, проверить исходники и тесты, затем сделать минимальную проверяемую поставку. Сохранённый план сам по себе не поручает менять код.
- **С чего начать сейчас:** пункты №1–№20, №22–№29, №36 и №39 закрыты (№21, №30–№35, №37–№38 и №40–№46 заблокированы API): regex и целое слово в поиске, «В чат» с точным Git-патчем, «Проверить индекс» с замечаниями на строках и выбором глубины «Быстро/Глубоко», «Черновик» сообщения коммита, «Уточнить» в Inline Edit с предыдущим ответом в контексте, разрешение конфликта с предпросмотром до записи, цепочка правил проекта с пометкой применённых, сохранённые планы с передачей в открытую сессию, ручной захват запуска терминала с предпросмотром, пауза Tab с видимым временем возврата, отключение Tab для выбранных расширений, вторая панель редактора с независимой прокруткой, карточка следующего файла после принятия Tab, диагностика линтера в запросе Tab, определения и ссылки по тексту открытых вкладок JS/TS, переименование символа с предпросмотром, запуск `npm test` с переходом к упавшей строке, замер поиска и решение не внедрять индекс, исключения `.cursorignore`/`.cursorindexingignore`, «Спросить о проекте» по найденным строкам, сравнение с фактической базой ветки, поиск по прошлым разговорам через `sessionQuery` с фильтром рабочей папки, вложение одного хода из найденного разговора с предпросмотром объёма, Debug-журнал для гипотезы, двух прогонов и очистки логов, пакет заметок и рабочие копии Git. №21 (multi-root) заблокирован отсутствием API Harness. Тесты — [search.test.mjs](../tests/search.test.mjs), [rules.test.mjs](../tests/rules.test.mjs), [plans.test.mjs](../tests/plans.test.mjs), [ignore.test.mjs](../tests/ignore.test.mjs), [scm.test.mjs](../tests/scm.test.mjs), [host.test.mjs](../tests/host.test.mjs), [client.test.mjs](../tests/client.test.mjs).
- **Состояние реестра:** закрыты №1–№20, №22–№29, №36, №39 и №48. №21 и №30–№35, №37–№38, №40–№47 закрыты конкретной причиной в реестре. №49–№68 (раздел D, командные и платформенные сценарии) по решению пользователя не строятся в ядре IDE: они остаются в реестре как ориентир для отдельных инициатив, интерфейс в панели для них не рисуется. Следующего локального шага нет.
