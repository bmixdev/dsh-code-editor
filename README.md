## English summary

A Monaco code editor plugin for DeepSeek Harness: an editor tab in the right
sidebar, a file tree of the session workspace, AI inline completions (Tab /
Ctrl+Space) with a provider-and-model chooser, an in-app settings drawer, API key
storage through the DSH credential store, guarded save with version checks, and
"quote to chat". Install with
`plugin_manager action=install_bundle target=<absolute path>`; run tests with
`node --test tests/`. MIT licensed.
